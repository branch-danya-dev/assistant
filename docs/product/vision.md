# Product intent and constraints

## Problem
A personal assistant that can answer questions but cannot reliably interact with a Windows desktop, project files, spreadsheets, communications and external sites does not solve the owner's actual workflow. A model must be paired with a controlled executor, remembered project decisions and verifiable outputs.

## Outcome
An always-available **software agent** (not conscious) with a persistent persona and memory independent of its replaceable LLM providers. It can plan tasks, act using approved capabilities, maintain project context, assess execution success and suggest new reusable skills. It provides local operation when possible and opt-in cloud intelligence when necessary.

## Prioritized user workflows
1. Research suppliers and build a sourced comparison including prices, minimum orders and lead times.
2. Create/modify DOCX, PDF, spreadsheets and financial models with programmatically verified results.
3. Operate an approved browser session for research, navigation and permitted form drafts.
4. Remember project requirements, decision history, open issues and their sources.
5. Maintain multi-step tasks, report blockers and resume safely after interruption.
6. Later: Telegram (bot first), email, calendar, Git/GitHub, Windows automation, CLO adapter, voice.

## User experience invariants
- One persistent identity across model upgrades and provider switches.
- The agent distinguishes what it knows, infers and has verified with tools.
- It clearly distinguishes drafted, staged, attempted and completed actions.
- User can inspect/modify/export/delete stored memories and abort tasks.
- External communication, purchases and privileged changes cannot be smuggled through model/tool outputs.

## Non-goals (initially)
Multi-user SaaS, AGI/sentience claims, autonomous weight updates, arbitrary self-modification, unmanaged browser credential extraction, general-purpose unattended OS control, unbounded recursion and unlimited API spend.

## Assumptions vs owner decisions
The conversation confirms option C (autonomous personal agent) and a practical tool focus; proposed technologies and exact privacy/approval defaults remain *provisional* pending implementation testing and owner review. Never present them as definitively approved.
